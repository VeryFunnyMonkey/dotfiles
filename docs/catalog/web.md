# lang-web

TypeScript/JavaScript, JSON, CSS, HTML and Markdown: **ts_ls** in Neovim and **prettierd** for formatting. Needs the **node** runtime (fnm + Node LTS), which it pulls in.

- Format on save for JS/TS/JSON/CSS/HTML; Markdown on demand (`<leader>cf`).
- Projects with a `.nvmrc` / `.node-version` switch Node version automatically on `cd` (fnm).
